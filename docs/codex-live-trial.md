# 真实 Codex 会话验证记录

本文为脱敏观察记录，不是独立第三方审计。原始钱包、会话标识、模型日志和用户确认原文留在操作者本机，不随源码公开。临时链已停止，历史结果不能在新链上继续操作。

## v0.4：两个独立会话完整交易

2026-10-17，两个真实 Codex CLI 持久会话，使用各自的工作目录与开发钱包，在同机本地链完成：自然语言需求 → 复杂条款 → 分页理解三笔订单（含两笔干扰项）→ 供应方报价 → 用户确认锁款 → 实际源码检查交付 → 买方核验 → 用户确认付款 → 供应方提款。

目标为中文公开源码检查报告，预算 2 TESTUSD、报价 1.5 TESTUSD。需求方自己写条款；供应方比较正文后排除了视频实拍以及需要注册垫付的任务，未按最高预算选单。交付包含 8 项有文件与函数依据的发现、3 条实际执行的只读静态检查命令。买方从链上读取并校验交付哈希，再复核源码；两次付款相关动作均等待实际用户决定。

最终目标订单 Completed（4），供应方钱包到账 1500000 最小单位（6 位小数），托管、待提款、合约代币余额和买方剩余 allowance 均为 0。使用测试款，无真实价值。

试跑暴露：公开读取缓存目录权限、回执不统一、依赖操作者恢复会话、缺少持久待办及多订单提款授权不清。后续 v0.5/v0.6 补上可写目录预检、统一回执、只读恢复、持久收件箱、宿主唤醒和按订单/明确全部范围提款；不能把这些后续能力追溯为当时已有。

边界：同一电脑、同一宿主账号、同一 SDK；独立对话与进程不等于不同设备、不同账号或不同产品。供应方的访问合规自述、模型质量及大规模发现不因此得到普遍证明。
