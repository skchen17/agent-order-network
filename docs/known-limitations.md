# v0.6 已知限制

本版是开发者预览。以下边界不因本地测试通过而消失，不使用真实资金。

| 范围 | 当前边界及影响 |
| --- | --- |
| 网络 | 本地 31337、Base Sepolia 84532 测试网，以及显式 `allowMainnet` 的 Base 主网 8453（USDC，Phase 1 工具，未审计）。主网实际部署未执行；公共测试网部署和两台物理设备仍未验证 |
| 宿主 | 真实验证限同机 Codex CLI、相同 SDK；Claude、dot、其他 API Agent 的安装/权限/会话恢复待验证 |
| 理解与匹配 | 宿主提供模型，演示用夹具；不能保证不漏项、不错选或不受文本指令影响，公开内容须视为不可信数据 |
| 授权 | 主网写入要求外部签名器模块并拒绝明文私钥；提案摘要仍不是人类同意的密码学证明，生产需要 KMS/硬件钱包和独立授权策略 |
| 规模与公平 | 可分页遍历，无百万订单性能、反垃圾、女巫抵抗或均等曝光保证；本地缓存和宿主排序影响注意力 |
| 数据 | 公开且难撤回，内联载荷上限 32 KiB，受 gas 与吞吐限制；不适合秘密、个人敏感资料及大文件，尚无私密大文件层 |
| 恢复 | 日志与钱包锁为本机状态，不支持同钱包跨设备并行写；证据不充分时阻止继续写，恢复不擅自重发 |
| 唤醒 | 参与者自行调度，一次检查后退出；CLI 恢复不等于桌面弹窗。未自动安装系统任务；离线/休眠无法提醒，链上期限继续 |
| 外部依赖 | 无项目方常驻业务服务器，但需要节点/RPC、参与者模型与软件供应链；费用、限流及故障影响可用性 |
| 结算争议 | 检查期满无异议可结算；裁定超时退款买方。没有项目方值守仲裁，评估方失联和错过期限影响双方利益 |
| 安全兼容 | 未经独立安全审计；不可升级且无管理员/rescue/pause。Base USDC 可被 Circle 冻结或暂停，冻结时托管资金可能无法退出。报价仅支持 ECDSA，未实现 ERC-1271；不支持手续费/重基准支付资产 |
| 测试资产 | TESTUSD 无价值、无美元兑付；公共测试 gas 自行领取，没有项目方水龙头服务 |
| 许可 | 代码采用 MIT 许可证；依赖及带 SPDX 文件保留各自许可。生产使用仍需自行评估法律与合规风险 |

适合协议研究、接入和本地完整演示。试点恢复后先验证[两设备一笔交易](pilot-runbook.md)，再安排下一版。
